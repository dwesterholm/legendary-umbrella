<objective>
Render the holistic-data-only brief so the Ringvägen 122 surface stops dead-ending, mark it
explicitly as data-derived rather than image-derived (D-14-04), and prove no rendered copy
implies "låg kr/m² ⇒ renoveringsobjekt" (D-14-06 UI guard).

Purpose: `gallery-condition-vision.tsx`'s `visionRanButEmpty` branch (~lines 135-140) currently
dead-ends with "För osäkert för att visa — inga bildbaserade slutsatser kunde dras med rimlig
säkerhet." That exact line is the Ringvägen 122 scenario: the candidate reached analysis and left
with nothing actionable. This plan replaces that dead end with the brief when one exists, and adds
the brief below the three `visionSkippedReason` explanations too — because in all four states there
are zero image-derived claims while comps + hedonic data are still available.

non-empty guarantee. NO R_med/U_med positioning cards, NO avgift/debt cards, NO tiered cost/profit
— those are Phase 15's `OpportunityBrief`. This plan renders the pre-composed
`HolisticBrief.items[].text` strings and nothing else.

Output: a new data-only sub-block in `gallery-condition-vision.tsx`, the `holisticBrief` prop
threaded from `discovery-results.tsx`, and component tests covering all five states plus the banned
copy.
</objective>
