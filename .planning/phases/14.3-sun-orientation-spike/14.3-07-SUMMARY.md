# Phase 14.3 Plan 07: Sun in the weekly run Summary

**Every flat in the weekly run now gets its facade, source, confidence and hours of sun (free and with neighbouring houses in the way) from the cached OpenStreetMap map before ranking; the table and mail show three Sol columns, the coverage line says "sol härledd 75 av 77 (97,4 %)", and Overpass is contacted only when the map is 31 days old.**

## Performance

- **Duration:** about 24 min (including one free live run of about 6 min)
- **Started:** 2026-10-13T15:40:00Z
- **Completed:** 2026-10-13T16:05:00Z
- **Tasks:** 3
- **Files modified:** 7 (no file created)

## What it means

Before this plan the sun pieces existed but the weekly run did not call them, so every live row had no sun fact. Now each candidate is looked up in the cached map of innerstan, its street and courtyard side are found, and the hours of direct sun on 21 March, June and December are counted, once with nothing in the way and once with the neighbouring buildings in the way. The ranking already counts sun through the taste bonus (plan 06), so the sun fact has to be attached before ranking; it is. The table, the HTML mail and the tracked-listing block show the same three cells. The map is a 13 MB file that is downloaded at most once a month; a normal weekly run reads it from disk and never contacts Overpass.

## Accomplishments

- `computeSunFact` composes footprint, stated facades, precedence and hours in one pure call; a side with a window point and a floor gets walls within 250 m and a shade range, a side without a point or a flat without a floor gets theoretical hours only, an okänd flat gets none.
- `runFitPipeline` applies `deps.sunOf` to window, outside and not-comparable rows before `rankFit`, so the taste bonus, the table and the coverage see one fact. Without `sunOf` nothing changes.
- The weekly run decides about Overpass with plan 02's rule: fresh prints "ingen hämtning (gräns 31 dagar)", a dry run only prints the decision, a replay never downloads, `--osm <fil>` reads that file and skips the refresh in both modes. The Overpass client is loaded by exactly one dynamic import.
- Three Sol columns and the pinned coverage item in the table, the mail and the tracked block; the sun report block after the coverage line.
