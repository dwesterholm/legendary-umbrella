<decisions>

### What "sun coverage" means for the table (phase exit)
- **D-01:** Phase exit = the weekly table carries, for ≥ 80 % of candidates, (a) an inferred main-window/balcony facade with a confidence label and its SOURCE ("angiven", "planritning", "fastighet/gata", "okänd"), and (b) theoretical sun hours per facade for the three seasons from `sun-path.ts`; PLUS, for the top section ("Förväntat under 4 M") at least, an OBSTRUCTED estimate (neighbouring buildings ray-checked) if the spike finds usable height data — otherwise the obstructed part is reported as "not available: <reason>" with the measured coverage and the phase still closes on (a)+(b). Taste's sun part consumes the inferred facade with the confidence as a multiplier (D-07).
- **D-02:** Never fabricate. Unknown stays "okänd" (score 0). Every inferred facade carries `source` and `confidence` ∈ [0, 1]; the table shows e.g. "S (planritning, 0.8)".

### Orientation inference (two routes, both tried, measured against each other)
- **D-03 Floor-plan compass via vision.** Among the broker photos, detect floor-plan images (vision already sees the gallery; the floor-plan is usually the last 1–2 images, white background). Ask the EXISTING Anthropic vision pass (new prompt section, same strict-output constraints — memory `anthropic-structured-output-limits`: keep the schema slim; no new nullable-union explosion) for: north-arrow present? bearing of north on the image (0–360) with confidence; which side of the plan has the balcony and the largest windows/room; → facade = side bearing relative to north. Cost: reuse the already-sent floor-plan image in the same call where possible; else one extra call per flat (≈0.4 kr). Cache with the vision cache.
- **D-04 Building footprint via OpenStreetMap.** Overpass API (public, free, rate-limited; be polite: ≤ 1 req/s, one bbox query per run for all candidates, cache under `.planning/calibration/data/osm-cache/` gitignored). Snap the flat's lat/lng to the nearest `building` way; compute the bearing of the footprint edge facing the named street (match the street via `addr:street` on the building or the nearest `highway` way with that name); street-facade bearing → facade. Courtyard side = opposite. Confidence from distance-to-building and edge-length. This gives "street side faces S" without knowing which rooms are where; combined with D-03 (balcony side) it becomes "balcony on the street side, facing S".
- **D-05 Precedence:** stated text > floor-plan compass > footprint/street. If two sources disagree by > 90°, mark `konflikt`, confidence halved, show both.

### Obstructed sun hours (the spike proper)
- **D-06 Data sources to probe, in order:** (1) OSM `building:levels` / `height` coverage within the innerstan bbox (measure the % of buildings with either); (2) Stockholms stad open data (Dataportalen: "3D-byggnader" / "Byggnader LOD") and Lantmäteriet open data ("Byggnad" / "Höjddata" / "Ytmodell") — check licence (CC0/CC-BY), format (CityGML / GeoPackage / GeoJSON / LAZ), download size, and whether a bbox cut is practical; (3) fallback: assume `height = levels × 3 m + 2 m`, and if `levels` is missing assume the innerstan median (5–6 storeys ≈ 18–20 m) with a flag. Ray-check: for each hour of the 21st of Mar/Jun/Sep/Dec, from the flat's facade centre at `floor × 3 m + 1.5 m`, test whether the sun ray (azimuth/altitude from suncalc) intersects any neighbouring footprint within 150 m whose top is above the ray; count unobstructed hours per facade. ±1 h target; no room-level modelling; no trees.
- **D-07 Taste integration:** sun part = facade weight (east 1.0 / south 0.7 / …) × confidence × obstruction factor (obstructed hours / theoretical hours for the morning+midday window, if available, else 1). Cap unchanged (3 % of resale). `taste.ts` stays pure; new modules are pure; `niche-score.ts`/`flags.ts` untouched.

### Delivery
- **D-08** Headless only (the weekly script and the HTML mail get "Sol" columns: facade/source/confidence, theoretical hours (Mar/Jun/Dec morning+midday), obstructed hours when available). No UI.
- **D-09** Cost ceiling per weekly run for this feature: ≤ 30 kr vision extra (cached), 0 USD Apify, Overpass free and cached; one-off data downloads ≤ 2 GB on disk, gitignored.
- **D-10** Evidence run on the current 77 candidates: coverage per source, agreement rate between D-03 and D-04 where both exist, Folkungagatan 61's inferred facade (truth: south, balcony street side — from the Hemnet text) as the calibration row, a second known flat if any listing states a facade (2 do).
