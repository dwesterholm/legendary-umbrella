The OSM extract file contract (plan 02 writes the real cache in this exact shape; this plan's schema parses it; the fixture uses it too):
- `version`: literal 1
- `attribution`: string that contains "OpenStreetMap contributors" (value used everywhere: "© OpenStreetMap contributors, ODbL 1.0, https://www.openstreetmap.org/copyright")
- `fetchedAt`: ISO-8601 UTC timestamp of the download; `osmBase`: Overpass `osm3s.timestamp_osm_base`
- `bbox`: { south, west, north, east } in degrees
- `buildings`: Overpass elements of `way["building"](bbox);out geom tags;` = { type "way", id, tags, geometry [{ lat, lon }], bounds? }
- `relations`: elements of `relation["building"](bbox);out geom;` = { type "relation", id, tags, members [{ type, ref, role, geometry? }] }
- `roads`: elements of `way["highway"]["name"](bbox);out geom tags;`
- `source`: optional string

The SunFact contract (defined in sun-fact.ts here; plans 04-08 fill and read it; every number already rounded as in must_haves):
- `source`: "angiven" | "planritning" | "fastighet/gata" | "okänd" (D-01 labels, NFC strings)
- `confidence`: number in [0, 1]; `unknownReason`: string or null (set exactly when source is "okänd")
- `conflict`: boolean; `conflictWith`: { source (not "okänd"), facade } or null
- `sides`: up to 4 entries of { side: "angiven" | "planritning" | "gata" | "gård", facade, bearingDeg (number or null), share (0..1), point ({ lat, lng } or null), hours (SideHours or null) }
- `footprint`: null or { osmId ("way/<id>" or "relation/<id>"), inside, snapM, streetBearingDeg, streetFacade, courtyardBearingDeg, courtyardFacade, confidence, frontageM, streetDistM, ambiguous, floorAboveLevels }
- SideHours: { z (flat height m, or null), heightsEstimated, mar, jun, sep, dec: DateHours }
- DateHours: { theoreticalWindow, theoreticalDay, obstructedWindow: Range or null, obstructedDay: Range or null, floorBelowWindow: number or null }
- Range: { low, nominal, high } (low = least sun, neighbours +3 m; high = most sun, neighbours -3 m)
