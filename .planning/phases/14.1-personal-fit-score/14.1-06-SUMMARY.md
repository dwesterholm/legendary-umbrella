# Phase 14.1 Plan 06: Reno cost from vision claims, taste bonus, vision cap Summary

**Vision verdicts now turn into a reno cost by tested Swedish regexes (negation first, worst state wins, priced from the cost matrix), the taste bonus exists as a pure table-driven module, and the vision spend ceiling is 25 SEK.**

## What this plan does, in plain terms

Three separate pieces, none of which calls the network or spends money.

1. **Reno cost from vision.** The picture reader already writes short Swedish sentences such as "Köket verkar inte renoverat". This plan sorts each kitchen, bathroom and overall sentence into fresh, ok or dated, and prices the result from the existing cost matrix. The dangerous trap is a sentence like "orenoverat" or "inte renoverat": it contains the word "renoverat", and a naive check reads it as a renovated flat, which would hide a 427 500 kr job. Negations are checked first, so those read as dated. If several sentences cover the same room, the worst one wins, so a cost is never understated. A room nobody wrote about is "unknown" and priced as a cosmetic refresh, never as free.
2. **Taste bonus.** A small add-on to resale value for sunny flats (up to 3 %) and flats near streets Daniel likes (up to 2 %). It orders flats whose money case is close; it cannot rescue a bad deal. Missing information gives 0, never a penalty.
3. **Vision cap.** The per-search ceiling on picture-reading spend rises from 10 to 25 SEK so a 20-flat headless run fits. The in-app search still reads pictures for at most 8 flats, so what the app spends per search does not change.

- **Found during:** Task 1 (writing the table test)

### Interface choices that differ from the plan text

- **Negation window.** The interface comment says `(ej|inte|icke|aldrig) [ett ord] renover...`, one optional word. I allowed up to three words without punctuation, because a one-word window reads "Köket ser inte ut att vara renoverat" as fresh, which understates cost. The risk in the other direction is a false "dated" (overstated cost) for a sentence such as "ej bara slitet utan nyrenoverat", which is the safe side. Tests cover both the three-word case and the sentence-boundary stop.
- **`renoBundle` third argument.** The tracer had `renoBundle(states, source)`. The plan wants the band as the optional second argument, so `source` is now third. No code outside tests called it with a source.
- **Source for an empty read.** See key-decisions.

**Total deviations:** 1 auto-fixed (bug), 3 interface choices.
