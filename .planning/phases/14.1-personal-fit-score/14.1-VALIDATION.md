- **After every task commit:** the task's `<verify>` command (targeted vitest files + `npx tsc --noEmit`)
- **After every plan wave:** `npm run test && npx tsc --noEmit && npm run lint`
- **Before `/gsd-verify-work`:** full suite green, offline replay (`npx tsx scripts/fit-score.ts --replay src/lib/discovery/__fixtures__/forsale-snapshot.fixture.json --model data/hedonic-model.json`) green, then the single live run (14.1-10)
