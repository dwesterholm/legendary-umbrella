## Accomplishments

- Below-asking sales no longer look like premiums. Booli writes them with an en dash or minus sign; the old parser read those as positive, so every premium in the slutpris data would have been biased upward. A missing label now stays null instead of becoming 0.
- A detail page that shows a balcony now beats a search card's `false`, which only means "not listed on the card".
- The calibration listing's own wording ("Södervända fönster", "sol hela dagen") is now readable by the extractor.
- Found and fixed a second bug while testing: the existing east keywords (`österläge`, `österut`, `österorienterad`, `österbalkong`) could never match after a space, because JavaScript's `\b` ignores ö, ä and å. East orientation had been silently undetected in running text.
- The replay snapshot for 14.1-03 is committed, and the prototype pull is saved under `.planning/calibration/data/` (untracked).

## Decisions Made

- `sydöst` matches only with a direction suffix (`läge`, `vänd`, `orienterad`, `balkong`) so a region phrase like "sydöstra Sverige" stays null. It adds both south and east when it matches.
- Sun phrases come from the broker description first, the Booli detail description only as a fallback.
- All four patterns now carry the `iu` flags; the lookbehind `(?<!\p{L})` is only used on the ö-initial east alternatives.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Pre-existing east keywords never matched after a space**
- **Found during:** Task 3 (writing the "Östvänd balkong" and non-ASCII boundary tests)
- **Issue:** `\bösterläge\b`, `\bösterut\b`, `\bösterorienterad\b`, `\bösterbalkong\b` used `\b` before ö, which JS treats as a non-word character, so they could not match anywhere except directly after a letter. The plan's R-04c guidance asked for the lookbehind on the new tokens only.
- **Fix:** Same `(?<!\p{L})` lookbehind on those four existing alternatives, covered by three new real-string tests ("österläge", "österut", "Österbalkong") and the place-name guards ("Östermalm", "Österåker").
- **Files modified:** src/lib/discovery/sun-path.ts, src/lib/discovery/sun-path.test.ts
- **Verification:** sun-path.test.ts 52/52, including all WR-01 place-name regressions
- **Committed in:** dc195c2

**2. [Rule 3 - Blocking, self-inflicted] First draft of toSignedPct had single-backslash regex escapes**
- **Found during:** Task 2
- **Issue:** The helper lives inside a template literal; unescaped `\s` and `\d` collapse to plain letters, which broke the regex (9 tests failed).
- **Fix:** Doubled every backslash, as the existing `\\u00a0` and `\\d` usages do.
- **Verification:** page-functions.test.ts and sold-schema.test.ts 41/41
- **Committed in:** 8dd6b8a (never committed in the broken form)
