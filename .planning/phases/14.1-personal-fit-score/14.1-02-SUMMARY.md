## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Probe balcony heuristic gave a false negative**
- **Found during:** Task 2 (reading the live run output against the saved flight text)
- **Issue:** The first analysis reported `balcony: absent` for the Kungsholmen page. A regex over the `amenities` array stopped at the first nested `]`, so the `Amenity` key `balcony` was missed. Taking that output at face value would have recorded SOLD_DETAIL_BALCONY as absent.
- **Fix:** Analysis now reads `Amenity` objects (key and label) directly. Re-ran offline from the saved dump with `--analyze` (no spend) and checked the three flight files by hand: `elevator, balcony` on one page, empty list on two.
- **Files modified:** scripts/probe-fit-sources.ts
- **Committed in:** 6a597a7

**2. [Rule 3 - Blocking] Acceptance grep matched the token presence-check line; Decisions key count was 10**
- **Found during:** Task 2 verify
- **Issue:** `console.log(\`APIFY_API_TOKEN: ...satt/saknas\`)` matched the plan's no-token-in-console grep even though it prints no value, and the pasted ledger line began with `APIFY_SPEND_USD:`, giving 10 key lines where the verify demands exactly 9.
- **Fix:** The variable name sits in a constant (`TOKEN_ENV_NAME`) and the script prints `Apify-kostnad:` for the ledger line. Output content is unchanged otherwise.
- **Files modified:** scripts/probe-fit-sources.ts, 14.1-PROBES.md
- **Committed in:** 6a597a7

### Plan divergences that are not bugs

- The plan said to copy navigation and challenge handling from `APOLLO_PAGE_FUNCTION`. That function has none (the actor loads the page before it runs; it is a single `page.evaluate`). `RAW_DUMP_PAGE_FUNCTION` mirrors that shape and reads the inline script text (the proven read), falling back to the `window[Symbol.for("ApolloSSRDataTransport")]` array only when no inline transport script exists.
- Added two flags the plan did not list: `--dry-run` (prints the planned URLs, spends nothing) and `--analyze <dump>` (re-runs the analysis offline). Both exist to keep the single paid run from needing a second one.
