# Phase 14.5 Plan 03: valuation-compare Summary

**Offline comparison of two to four valuation run records with Folkungagatan 61 first, coefficients with SE, stage-2 values flagged against each model's own cap, and the R-01 ±12 % rule as tested code**

## Performance

- **Duration:** about 13 min (start time was not recorded; estimated from the previous plan's end)
- **Completed:** 2026-10-17T14:16:05Z
- **Tasks:** 2
- **Files modified:** 5 (all new)

## Accomplishments

- `buildValuationCompare` and `renderValuationCompareMd` take run records of any model version, join flats by id, and print Folkungagatan 61 first ("plats 29 → 17"), the top 15 of every column side by side, and the 10 largest rank moves between the first and last column. With an intermediate column the line reads "plats a → b → c".
- With model files it prints every stage-1 coefficient as beta ± SE per column and the stage-2 balcony and four build-year values, each marked "(på taket ±X %)" against that model's own cap. On today's committed model, balcony +8,0 % and 1961-1990 -8,0 % are on the ±8 % limit, which is what Daniel's UAT item 1 asks about.
- With the fit-report JSON it adds raw stage-2 values with SE, the stage-2 cross-validation (no step, ±8 %, ±12 %), a note that stage 1's cvRmseLog cannot tell the caps apart, the avgift/debt correlation and the ceiling line. `capDecision` picks ±12 % when its error is not worse than ±8 % (an exact tie picks ±12 %) and prints both numbers; the JSON carries it as `capDecision`, with `capStepNeeded` next to it.
- When the tracked flat is in both a ±8 % and a ±12 % column, the report states the resale difference in kronor.
- Tool check on the 14.4 records: Folkungagatan 61 goes from plats 29 to 17 (resale 5 006 594 kr to 5 503 113 kr, profit 778 545 kr to 1 123 047 kr). Committed under `evidence/compare-14.1-14.4/`.
