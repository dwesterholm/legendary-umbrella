Things worth knowing:

- **Balcony side is the closest field.** Both variants read the balcony side right on 12 of the 14 decided flats. The bar is not missed because of wrong answers but because only 9 (a) or 13 (b) of 14 flats get a believed answer and the holdout has only a handful, so the interval is wide. The evidence-rules prompt (b) reads a believed answer on more flats but gets 2 of its 6 holdout answers wrong.
- **The evidence rules made korsdrag worse.** Variant b says "windows on two opposite sides" on 19 of the 32 dev flats and is right on 3. Variant a says it on 7 and is right on 2. The 4 true two-opposite flats in the set are too few to say more, and the holdout rests on a single two-opposite flat, so any holdout number for this field would be one flat wide. The rule in b that a long flat with windows in both short ends counts as two-opposite is the likely cause, but this is a reading of the numbers, not a tested explanation.
- **Folkungagatan 61 (truth: balcony street, windows one side, bedroom street):** variant a (the baseline round) reads balcony "courtyard" (the known misread), bedroom "courtyard" and windows "twoOpposite", all three wrong, at confidence 0,55. Variant b reads balcony "unknown", bedroom "unknown" and windows "twoOpposite" (wrong) at 0,4. Jev also read balcony "unknown" (48 %), with courtyard 35 % and street 17 %, windows "twoOpposite" at 51 %, bedroom "unknown" (80 %) and no street evidence (63 %). At any sensible gate Jev would abstain on this flat, which is the safe failure.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug in the plan] The Jev cost example is ten times too high**
- **Found during:** Task 0
- **Issue:** The acceptance criteria say a 1 200-token request is about 0,0005 USD. At 0,042 USD per million tokens it is 0,0000504 USD (0,00055 kr). R-10's own figure of 0,005 kr per flat matches the correct arithmetic only if a flat is about 10 000 tokens.
- **Fix:** The test pins the correct figures (1 200 tokens = 0,0005544 kr, 10 000 tokens = 0,00462 kr). The live smoke then showed a full four-picture flat is about 18 800 tokens, 0,0087 kr.
- **Files modified:** `src/lib/discovery/layout-experiment.test.ts`
- **Committed in:** `fcb0ee9`

**2. [Rule 3 - Blocking] Picture preparation needs sharp, which was not a declared dependency**
- **Found during:** Task 0
- **Issue:** Booli serves WebP; Jev takes PNG or JPEG only, upright, 280 to 1568 px. The plan said to reuse existing image preparation, but none exists in the repo. sharp 0.34.5 was already installed and locked as an optional dependency of next.
- **Fix:** `npm install --save-exact sharp@0.34.5`. The lockfile change is the declaration plus three entries (`sharp`, `@img/colour`, `detect-libc`) losing their "optional" mark. No new package version came in.
- **Files modified:** `package.json`, `package-lock.json`
- **Committed in:** `fcb0ee9`

**3. [Rule 3 - Blocking] A paid round refused to start: two locked truth rows are not in the default snapshot**
- **Found during:** Task 2 (dry run)
- **Issue:** `--run` read picture links from one snapshot only. Flats 4538414 and 439232 (the two that plan 07 found in the older snapshots) were missing, and a paid run stops when any flat of the set is missing.
- **Fix:** Without `--snapshot`, `--run` reads from the 14.4 snapshot first and then the other three stored snapshots (the first that has a flat decides its links). An explicit `--snapshot` still means exactly that one file.
- **Files modified:** `scripts/layout-accuracy.ts`
- **Verification:** dry run reports 60 flats, 60 readable; both rounds read all 60.
- **Committed in:** `519b11c`

**4. [Rule 2 - Missing critical] The smoke needed a per-variant cap and a gate on the right key**
- **Found during:** Task 0
- **Issue:** The smoke cap was a constant 1 kr and the gate checked only the Anthropic key; Task 0 asks for 0,1 kr and a TypeSafe key.
- **Fix:** `smokeCapSek` on the spec (0,1 for e, otherwise 1 kr) and `paidGate(spec)` checks `TYPESAFE_API_KEY` for a Jev variant. The client is created only after the gate.
- **Files modified:** `scripts/layout-accuracy.ts`, `src/lib/discovery/layout-experiment.ts`
- **Committed in:** `fcb0ee9`
