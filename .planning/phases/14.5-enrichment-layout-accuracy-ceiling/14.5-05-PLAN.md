<assumption_delta_decision>
- Noun now primary: the layout read is identified by a LayoutVariantSpec and its variant version (prompt, model, schema, call shape, image policy), no longer by the module constants of layout-read.ts alone.
- Decision: add-alongside for this plan, accepted as debt. The weekly production path keeps runLayoutReads and the 14.4 constants untouched while the experiments run through runVariantReads, because changing production before a variant is proven would re-key the production cache and spend money on an unproven read. Variant a is built from the production constants and an invariant test pins that they are equal, so the old singular read is already "variant a".
- What forces the promote: a variant passing the switch test in plan 12. Then production adopts that variant through runVariantReads (plan 12 task 3) and the singular constants become the definition of variant a only.
- Invariant test: every variant in LAYOUT_VARIANTS round-trips through runVariantReads and factFromVariantRead into a LayoutFact that layoutFactSchema parses and believedLayout can judge.
</assumption_delta_decision>

<objective>
Make it possible to run the four layout experiments of D-10 against the truth set at the true price, without touching the weekly read or its cache (R-04): fix the cost ledger first, then define the variants, their call shapes, their own caches, the two-step combination and the round-by-round decision, and give the runner its paid modes behind every guard.

Purpose: the 14.4 ledger bills the Sonnet read at Haiku rates (about 0,32 kr per read is recorded as 0,11), so a "40 kr" cap really allowed about 120 kr; and running a second prompt through the production runner would have deleted every stored read. Both must be fixed before the first paid round, and all four variants must be written down before anyone sees a result, so nothing is tuned on the truth set.
Output: a rate table, the corrected production ledger, the variant module, the Opus and two-step call shapes, and the runner's --run, --smoke, --report --variant and --decide modes. No paid call is made in this plan.
</objective>
