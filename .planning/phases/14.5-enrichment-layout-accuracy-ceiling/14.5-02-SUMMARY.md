# Phase 14.5 Plan 02: Layout accuracy rules and truth-set tools Summary

**The switch rule for the layout read is now code: precision of the answers that move money, at a gate chosen from the measured confidence curve on development flats, confirmed on locked holdout flats, with Wilson intervals and a 12-decided-row minimum, plus free tools to build, check and lock the truth set before any paid read**

## Accomplishments

- A truth file has a fixed shape (`layoutTruthFileSchema`): one row per flat with the Booli id, the truth for balcony side, living room on the balcony side, window sides and bedroom side ("undecidable" is a valid, counted answer), the judge's confidence, evidence words and a one-line note. Strict: an address or URL key is an error, and so is a link, a host or a street name inside a note.
- `believedLayout` in `layout-fact.ts` is the one place that says what a stored read is believed to say under a gate policy: per-field confidence when the fact has one, abstain when no floor plan was among the pictures, a trusted read version, photo evidence from an allowlist, a stricter gate for a positive korsdrag than for a negative. The accuracy module counts every "believed call" through it, so the rule that is measured and the rule that will run cannot drift apart. The 14.4 gate functions, the 0,6 gate and `LAYOUT_INFLUENCE_ENABLED = false` are untouched.
- Accuracy is measured as precision of the answers that move money: a believed street/courtyard balcony call (wrong on a flat with no balcony), a believed korsdrag "ja" (right only when the windows are on two opposite sides), a believed bedroom "courtyard". The curve has one point per distinct confidence the reads carry; the gate is the lowest threshold where precision stays at 75 % with at least 5 believed calls on the dev rows, walking down from the strictest and stopping at the first supported failure.
- A field passes only when it is measurable (at least 12 decided truth rows, else "ej mätbart (n = k)"), the file is locked with a holdout, a dev gate exists, holdout precision at that gate is at least 75 % over at least 5 believed calls, and dev plus holdout pooled is at least 75 % over at least 10. Every failing reason is listed. The variant passes only when all three fields pass. Everything prints with its Wilson 95 % interval, next to the raw (ungated) accuracy and the all-calls accuracy.
- D-12: street/courtyard calls count only for the model's evidence word `cars` or `courtyardGreenery`; `oppositeFacade` joins only if its own dev precision is at least 75 % over at least 5 calls. The by-evidence table is part of the report.
- Truth-set tools: `--judge-list` prints the Booli ids to judge (Folkungagatan 61 first, then a seeded order; URLs only with `--with-urls`, only allowed hosts, never a read); `--check-truth` catches a malformed or edited file; `--select-and-lock` fixes the measured set (at most 45 rows), a 50/50 stratified dev/holdout split (Folkungagatan 61 forced into the holdout), the read order, a hash of the rows and a hash of the written procedure, and refuses a second lock. Run on a scratch 60-row file it gave 45 rows (dev 24, holdout 21); a tampered note failed the hash check.

## Decisions Made

See `key-decisions` in the frontmatter. In plain words: the balcony and bedroom calls that rest on `oppositeFacade` are pooled when asking whether that evidence word earns trust; a file without a lock simply says "ingen låst holdout" instead of piling on consequences; a set that is too big is cut by priority and the cap wins; and the 14.4 reads have a single confidence, so the production curve is coarse until a variant stores per-field confidences.

The one judgement call that changes how hard the bar is: **5 believed calls on the holdout and 10 pooled** (the research proposed 10 on the holdout alone). A holdout of about 20 flats will hold perhaps 5 to 8 "korsdrag ja" calls, so the research rule could never pass and would decide the outcome by construction. The 75 % bar and the 12-decided-rows rule are unchanged. Flagged in coverage D6 for a human look.
