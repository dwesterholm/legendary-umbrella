## What this means

The phase is **closed on the evidence**. - **The first scheduled mail will be small.** The evidence run wrote the weekly memory (`watch-state.json`, 77 flats). Run it once right now instead of waiting for Monday:

```sh
launchctl kickstart -k gui/$(id -u)/com.bostadai.weekly-watch
```

Remove it:

```sh
launchctl bootout gui/$(id -u)/com.bostadai.weekly-watch
```

Optional, because this Mac goes to sleep after one minute and `caffeinate` cannot wake a sleeping Mac (a missed 07:00 run starts when the Mac next wakes, so without this the mail can arrive late). It changes a power setting and asks for your password, which is why it was not run:

```sh
sudo pmset repeat wakeorpoweron M 06:55:00
```

Caveats (also in `scripts/launchd/README.md`): it only runs while you are logged in; a closed lid on battery sleeps; to get real mail add `WATCH_SMTP_URL` and `WATCH_EMAIL_TO` (optionally `WATCH_EMAIL_FROM`) to `~/.zshenv`.
