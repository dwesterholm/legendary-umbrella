<objective>
Read the pictures of every candidate within a hard 60 SEK per run (WATCH-02, D-06, R-09), and prove it on a small paid run before the evidence run spends real money.

Purpose: plan 05 reads every candidate's pages for free, but condition ("skick") still comes only from picture reading, and D-17 needs condition known for at least 80 % of candidates. Reading ~75-100 flats costs about 0.41 SEK each (about 30-41 SEK for a first full run). Three parallel lanes keep the wall-clock time down, a per-lane cap means one run can never pass 60 SEK, and a cache keyed by listing and picture set makes later weeks cost only the new or re-photographed flats. Split from plan 05 so each plan fits one executor's context (checker W7); this plan also closes the Nyquist gap by exercising all three lanes for real on ~10 flats.
Output: runVisionPass capSek, vision-cache.ts (cache, chunks, the pinned Bildtolkning line), the shared json-store.ts, the script wiring, and two real smoke runs (paid, then cached).
</objective>
