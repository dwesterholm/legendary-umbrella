---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | vitest 4.1.8 (node by default; jsdom per file via `// @vitest-environment jsdom`) |
| **Config file** | `vitest.config.ts` (alias `@` -> `src`, setup `./vitest.setup.ts`) |
| **Quick run command** | `npx vitest run src/lib/booli src/lib/discovery` |
| **Full suite command** | `npm run test && npx tsc --noEmit && npm run lint` |
| **Estimated runtime** | ~6 s for the suite (baseline 1 440 passed / 3 skipped); tsc + lint ~40 s |
| **Live checks** | Free local runs through the headed browser (probe, smoke runs) and one paid evidence run; all executor-run, none manual |

---

## Sampling Rate

- **After every task commit:** `npx vitest run <the task's test files>` plus `npx tsc --noEmit` (each task's `<automated>` command)
- **After every plan wave:** `npm run test && npx tsc --noEmit && npm run lint`
- **Before `/gsd-verify-work`:** full suite green, then the plan 08 evidence run
- **Max feedback latency:** unit feedback under 60 s; live local runs (smoke, evidence) take minutes by nature and run in the background
