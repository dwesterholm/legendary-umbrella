# Phase 14.2 Plan 01: Local Browser Rung Summary

**A headed Chromium on this Mac now reads Booli for the headless scripts through the unchanged page functions: a real four-district run fetched 20 pages in about 33 s for 0,00 USD with no Apify token, and Apify is only an opt-in, capped fallback.**

## Accomplishments

- `transport.ts` now chooses the renderer. `runPlaywrightRender` goes to whatever a script installed with `setRenderer`, otherwise to `runApifyRender`, which is the old body moved verbatim (all literals intact). The in-app job never installs a renderer, so its Apify call is byte-identical; a test pins the input.
- `local-browser.ts` renders with a headed Chromium parked off-screen (sv-SE, Europe/Stockholm, 1280x900, one throwaway context per run, no profile, no storage state, downloads off). The page function string is compiled once with `new Function` and called with `{ page, request: { url } }`.
- Challenge handling: HTTP 403, 429, 503 or the text "Vänta...", "Just a moment", "Verify you are human" wait exactly 5 000 ms and retry once on a fresh page. A second challenge goes to Apify only with `allowApify` and under `apifyMaxRenders`; otherwise the Swedish error. 404 and 500 are ordinary errors with no wait. A 200 with no Apollo data is re-extracted once after 1 500 ms first.
- Safety: non-Booli URLs are refused before a page opens and never reach Apify (three bypass URLs tested). At most 2 pages are open at once, with 1-2 s between page starts. Pages close in `finally`, `close()` is idempotent, SIGINT/SIGTERM close the browser before exit 130/143, and one relaunch is tolerated after a disconnect.
- The two headless scripts default to the local browser (`--renderer`, `BOOLI_RENDERER`; no display and no choice is an error). Local mode needs no `APIFY_API_TOKEN` and skips the memory and monthly-headroom checks. `Renderare: lokal webbläsare` is the first stdout line.
- The spend block prints `Lokal webbläsare: ...` and `Apify-reserv: ...`, waits the shared 10 s settle delay (WR-05), then prints the one pinned runs-API line.
- `playwright` is pinned to exactly 1.60.0 in devDependencies (see integrity below).

In plain terms: Apify (the paid cloud browser) is now the backup, not the default. A weekly run on this Mac costs nothing for Booli pages. If Booli blocks a page twice, the run stops for that page and says so, unless you pass `--allow-apify`, which then spends at most 10 renders (about 0,59 USD) by default.
